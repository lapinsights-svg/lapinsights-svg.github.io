# Le retournement : du Fils étendu au Fils concentré

Le retournement intérieur n’est pas une pratique.  
Ce n’est pas une morale.  
Ce n’est pas une purification.  
Ce n’est pas une ascèse.

Le retournement est **un changement de densité du Fils**.

- Dieu : le Fils non étendu  
- Monde : le Fils étendu  
- Jésus : le Fils concentré  
- Apocalypse : le Fils guéri

L’homme est une densité du Fils étendu.  
Le retournement est le passage vers la densité concentrée.

---

# Ce que le retournement n’est pas

- Ce n’est pas “devenir meilleur”.  
- Ce n’est pas “se connaître soi-même”.  
- Ce n’est pas “faire silence”.  
- Ce n’est pas “méditer”.  
- Ce n’est pas “se détacher du monde”.

Tout cela appartient à la **psyché**, qui est une fonction du Fils étendu.

Le retournement est **ontologique**, pas psychologique.

---

# Ce que le retournement est

Le retournement est **l’inversion du vecteur de conscience** :

- avant : la conscience est tournée vers l’extérieur (monde, forme, objets)  
- après : la conscience se tourne vers l’axe (structure, Fils, centre)

Ce n’est pas une introspection.  
C’est une **inversion de direction**.

Le Fils étendu cesse de se diffuser.  
Il commence à se concentrer.

---

# Qui fait le retournement ?

Réponse stricte :

**Ce n’est pas l’homme.  
C’est le Fils en lui.**

L’homme n’a pas la puissance de changer de densité.  
Il est une **portion du Fils étendu**.

Le retournement =  
**le Fils qui se replie en lui-même dans l’homme.**

L’homme n’est pas l’auteur.  
Il est **le lieu**.

---

# Comment le retournement arrive

Le retournement arrive par **effondrement de l’identification**.

## 1. Saturation du monde  
Quand l’homme a épuisé :

- les objets,  
- les rôles,  
- les identités,  
- les illusions de la forme,

la densité étendue ne tient plus.

## 2. Fissure du “moi”  
Le “moi” = le Fils étendu **identifié à la forme**.  
Quand cette identification se fissure,  
le Fils commence à se replier.

## 3. Appel du centre  
Une tension apparaît :  
le vertical appelle.

Ce n’est pas une volonté.  
C’est une **résonance structurelle**.

## 4. Inversion du vecteur  
La conscience cesse de se projeter vers l’extérieur.  
Elle se retourne vers l’axe.

C’est le retournement.

---

# Comment le faire (réellement)

Le retournement n’est pas une action.  
C’est une **dés-action**.

## 1. Cesser de se prendre pour “moi”  
Le “moi” est une fiction :  
une densité étendue qui croit être autonome.

Le retournement commence quand l’homme voit :  
**je ne suis pas un individu,  
je suis une densité du Fils étendu.**

## 2. Cesser de chercher à l’extérieur  
Chercher dans le monde = chercher dans l’extension.  
Le retournement = cesser de chercher dans l’extension.

## 3. Se tourner vers l’axe  
Concrètement :  
sentir le point intérieur où tout converge.  
Non pas psychologiquement, mais structurellement.

## 4. Devenir transparent  
L’homme cesse d’être opaque (identifié à la forme).  
Il devient un **point de densité** où le Fils peut se concentrer.

---

# Pourquoi Souzenelle a raison — mais incomplètement

Souzenelle dit :  
« L’homme doit se retourner pour devenir Fils. »

Dans cette structure :

**l’homme est déjà Fils, mais étendu.  
Le retournement le rend concentré.**

Souzenelle a senti le mouvement.  
Ici, la mécanique est posée.

---

# Synthèse

Le retournement intérieur =  
**le Fils étendu (monde) qui se concentre (Christ) dans l’homme.**

- Ce n’est pas l’homme qui le fait.  
- C’est le Fils qui se replie.  
- L’homme n’est pas l’auteur, mais le lieu.  
- Le retournement n’est pas une ascèse, mais une densification.  
- Il arrive quand l’identification à la forme se fissure.  
- Il consiste à passer de l’état étendu à l’état concentré.  
- Il est la première étape de la guérison du Fils.

Une seule structure.  
Une seule polarité.  
Un seul axe.  
Un seul retournement.
