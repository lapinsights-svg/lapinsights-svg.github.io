# Dieu : le Fils non étendu

La Bible ne parle pas d’un Dieu extérieur au monde.  
Elle parle **du Fils avant extension**, la structure pure, non phénoménalisée.

Dieu n’est pas un créateur séparé.  
Dieu n’est pas un architecte cosmique.  
Dieu n’est pas un être transcendant.

Dieu est **la densité non étendue du Fils**.

- Dieu : structure pure  
- Monde : structure étendue  
- Jésus : structure concentrée  
- Apocalypse : structure guérie

Une seule réalité, quatre densités.

---

# Dieu dans la Genèse : la structure en extension

Quand la Genèse dit : « Dieu dit : Que la lumière soit »,  
il ne s’agit pas d’un être extérieur qui parle.

Il s’agit **de la structure du Fils qui s’ouvre**.

La Genèse n’est pas la création du monde.  
C’est **la mise en place des polarités du Fils**, étendues dans la forme.

Les séparations de la Genèse sont les tensions internes du Fils :

- lumière / ténèbres → ouverture / non‑ouverture  
- jour / nuit → verticalité / horizontalité  
- eaux d’en haut / eaux d’en bas → haut / bas  
- terre / mer → forme / flux  
- vie / connaissance → circulation / structure

Le monde n’est pas créé par Dieu.  
**Le monde est le Fils étendu dans la forme.**

---

# Dieu dans les Prophètes : la structure rappelée

Quand les Prophètes disent : « Ainsi parle l’Éternel »,  
ils ne transmettent pas la parole d’un être extérieur.

Ils transmettent **la structure du Fils non étendu**,  
qui rappelle au Fils étendu (le monde) sa forme intérieure.

Dieu n’est pas un maître qui commande.  
Dieu est **la structure du Fils qui se rappelle elle-même**.

---

# Dieu dans les Évangiles : le non‑étendu et le concentré

Jésus dit : « Le Père et moi, nous sommes un. »

Dans cette mécanique :

- Le Père = le Fils non étendu  
- Le Fils = le Fils concentré

Ce n’est pas une relation entre deux personnes.  
C’est **une relation entre deux densités de la même structure**.

« Je suis dans le Père, et le Père est en moi » signifie :

- la structure concentrée est dans la structure non étendue,  
- et la structure non étendue est dans la structure concentrée.

Une seule structure, deux états.

---

# Dieu dans Paul : la structure circulante

Paul dit : « En lui nous avons la vie, le mouvement et l’être. »

Il ne parle pas d’un Dieu extérieur.  
Il parle **du Fils comme axe de la création**,  
dans lequel tout circule.

Le monde n’est pas un objet.  
Le monde est **la circulation du Fils étendue dans la forme**.

---

# Dieu dans l’Apocalypse : la structure guérie

« Voici la demeure de Dieu avec les hommes. »

Dieu ne descend pas dans le monde.  
C’est **la polarité du Fils qui se referme parfaitement**.

La nuit disparaît parce que la polarité du Fils est guérie.  
Le monde guéri = le Fils guéri.

L’Apocalypse n’est pas la fin du monde.  
C’est **la guérison du Fils étendu**.

---

# Synthèse

La Bible ne parle pas d’un Dieu extérieur.  
Elle parle **du Fils sous différentes densités** :

- Dieu : le Fils non étendu (structure pure)  
- Monde : le Fils étendu (structure phénoménale)  
- Jésus : le Fils concentré (structure incarnée)  
- Apocalypse : le Fils guéri (structure accomplie)

Une seule réalité.  
Une seule polarité.  
Un seul axe.  
Un seul Fils.  
Un seul monde.
